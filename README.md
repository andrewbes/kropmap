# 🗺️ Мапа Кропивницького

Інтерактивна карта міста Кропивницький з можливістю додавання власних міток та перегляду пам'яток.

## 📁 Структура проекту

```
SmartCityMap/
├── index.html              # Головна сторінка
├── styles.css              # Стилі CSS
├── script.js               # JavaScript функціональність
├── images/                 # Локальні зображення
│   ├── street_main.svg     # Зображення вулиці
│   └── square_heroes.svg   # Зображення площі
├── simple_image_generator.html  # Генератор зображень
└── README.md               # Документація
```

## 🚀 Запуск проекту

1. Відкрийте `index.html` у веб-браузері
2. Або запустіть локальний сервер:

   ```bash
   # Python 3
   python -m http.server 8000

   # Python 2
   python -m SimpleHTTPServer 8000

   # Node.js
   npx serve .
   ```

## 🖼️ Робота з зображеннями

### Локальні зображення

Всі зображення зберігаються локально в папці `images/`:

- `street_main.svg` - зображення вулиці Велика Перспективна
- `square_heroes.svg` - зображення площі Героїв Майдану

### Додавання нових зображень

1. Додайте зображення в папку `images/`
2. Оновіть шлях в `script.js`:
   ```javascript
   photo: "images/your_image.jpg";
   ```

### Генерація зображень

Використовуйте `simple_image_generator.html` для створення нових placeholder зображень.

## 🔧 Налаштування

### Додавання нових пам'яток

В файлі `script.js` додайте новий об'єкт в масив `streets`:

```javascript
{
  position: { lat: 48.XXXX, lng: 32.XXXX },
  title: "Назва пам'ятки",
  description: "Опис пам'ятки",
  photo: "images/your_image.svg",
  type: "landmark",
  icon: "🏛️"
}
```

### Зміна стилів карти

Стилі карти налаштовуються в масиві `mapStyles` в `script.js`.

### Зміна дизайну

Всі стилі знаходяться в файлі `styles.css`.
